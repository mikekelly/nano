# File utilities

`Seedling.Files.read(path, offset: 1, limit: 200, bytes: 16000)` returns `{:ok, %{text:, next_offset:, total_lines:, warning:}}`. Page with next_offset; oversized individual lines require a larger byte cap. `write/2` creates directories; `edit/3` requires a unique exact match and a change. `ls/2`, `find/2`, `grep/3` bound results. grep requires ripgrep (installed on this node). Errors are values. Tests: `MIX_ENV=test mix test test/seedling_files_test.exs` (1 passed). Exact edits currently single replacement only; glob find does not honor gitignore; grep reports general cap notice rather than exact truncation counts.
